# 多语言

模板内置简体中文（`zh`）和英文（`en`）。公开页面、工具目录与示例、登录与密码表单、账户中心、管理后台、博客正文和法律草稿使用同一套翻译机制。

## 切换与默认语言

- 语言使用地址前缀：`/zh/` / `/en/`，内页例如 `/zh/pricing`、`/en/billing`。路径语言优先于偏好 Cookie 和浏览器语言。
- 访问不带前缀的页面时，读取 `qihang-locale` 偏好 Cookie，再按浏览器 `Accept-Language` 选择支持的语言，并跳转到对应语言路径；没有匹配语言则回退英文。
- 官网和账户/后台顶部直接显示语言切换按钮，位于明暗模式按钮后；手机端同样直接显示，无需展开导航菜单。点击“文 / A”图标打开语言下拉菜单，选择简体中文或 English，当前语言显示勾选标记。
- 切换保留当前地址的其他参数，偏好保存一年。服务端首屏和客户端使用同一语言，`html lang` 随语言更新。没有跨请求共享的可变语言变量。

本地调试中文使用 `http://127.0.0.1:4317/zh/`，英文使用 `http://127.0.0.1:4317/en/`。旧的 `?lang=zh` / `?lang=en` 链接会自动跳转到语言路径，并保留其他参数。

## 写界面文案

`src/i18n/core.ts` 负责语言选择、占位参数和词典查找；`src/i18n/react.tsx` 提供上下文与切换组件；英文词典在 `src/i18n/en.json`。中文原文作为稳定的消息键，中文显示无需额外复制一份字典。

```tsx
const { t: tr, locale } = useI18n();
<h1>{tr("账户概览")}</h1>
<p>{tr("第 {0} 页 · 每页 25 条", [page])}</p>
```

在英文词典加入相同的中文键和英文值，占位参数编号需保持一致。不要把动态数值、用户输入或编号拼入消息键；业务值只作为占位参数。日期使用 `formatDateTime(value, locale)`；界面日期格式随语言变化，时区仍统一为 Asia/Shanghai。金额币种仍由业务确定，切换语言不会换算汇率或更改商品价格。

`tests/i18n.test.ts` 会检查界面直接引用的消息键、占位参数、工具/博客目录翻译、请求隔离及语言相关 SEO 信息。新增界面后运行 `npm run check`。

## 内容与业务边界

- 邮箱、兑换码、任务/订单编号、支付商品绑定、用户输入、AI 已生成结果和用户资料保留原值。
- 语气、分类、任务状态等业务枚举在展示时翻译，提交给服务端的值保持原契约。
- 模板默认套餐名称、说明和权益有英文显示文案；管理员自己填写的套餐内容、操作原因等业务数据不自动机器翻译。可给固定的产品展示内容添加词典条目，或在具体产品中为 CMS/套餐增加语言字段。
- 已有生成接口调用不传 `locale` 时保持中文行为；英文界面传 `locale=en`，服务端严格校验。英文文案、摘要、邮件和社媒工具采用英文任务指令；润色保留原文语言，中英翻译继续按输入方向处理。私有系统提示词仍只在服务端。
- 验证与重置密码邮件根据发起请求的偏好 Cookie / 浏览器语言选择文案，链接和验证令牌保持原值。实际邮件投递仍需要配置 Resend。

## 搜索信息

公开页面使用对应语言的标题、描述和 Open Graph 信息。正式环境的 canonical 与 hreflang 使用 `/zh/` / `/en/` 路径，站点地图包含两种语言的公开地址。博客 JSON-LD 的正文语言、标题与描述同步变化。开发、预发布、账户和后台保持不可索引。

## 增加语言

增加新的词典文件后，在 `Locale`、支持语言列表、选择规则和词典注册中添加该语言，再扩展语言切换组件、日期格式与 SEO 语言映射。页面继续复用 `tr`，不需要复制整套组件或支付、积分、登录逻辑。新增语言需要完整的词典和对应的测试，不要将未完成翻译的语言暴露给用户。

## 路由与服务商设置

`src/i18n/routing.ts` 在路由输入/输出边界处理语言前缀，页面仍复用同一套文件路由。站内 Link、导航和客户端跳转自动生成语言路径；切换语言保留当前页面、记录类型等查询参数。路由内部的语言标记不会显示在浏览器查询参数中，不需要复制中文和英文两套路由文件。

`src/i18n/server-routing.ts` 负责无前缀页面、旧语言参数和 `/zh` → `/zh/` 的跳转。路径前缀优先，`/en/pricing?lang=zh` 会规范为 `/en/pricing`。

API、支付 Webhook、OAuth 回调、服务端函数、静态资源、robots.txt 和 sitemap.xml 均保持根路径。`APP_URL` 仍填写站点根域名，不加 `/zh` 或 `/en`。邮件重置链接与 Google 登录的页面回跳携带语言路径；已有支付渠道的无前缀页面返回地址也能经站点跳转到对应语言。
