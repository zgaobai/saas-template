# 博客维护

博客是随代码发布的内容模块，不需要额外数据库、CMS 或密钥。目前带三篇可替换的中文示例文章。

- `/blog`：文章列表。
- `/blog/文章标识`：文章详情，公开访问、服务端渲染。
- `/guide`：旧入口，永久重定向到 `/blog`。

## 添加文章

1. 在 `src/modules/blog/posts/` 新建一个 TSX 文件，默认导出正文组件。正文直接使用段落、标题、列表等语义 HTML，不需要把内容写成页面配置。
2. 在 `src/modules/blog/catalog.ts` 添加标题、英文 slug、摘要、分类、真实发布日期和更新日期、作者以及关联工具。此列表仅收录准备发布的文章；草稿不要加入。
3. 在 `src/modules/blog/article-body.tsx` 导入正文并添加 slug 对应项。类型检查会提示遗漏的正文映射。
4. 本地查看列表、详情及移动布局，运行 `npm run check` 后发布。slug 上线后尽量保持稳定，改动时应为旧地址设置跳转。

标题、描述、Open Graph、文章结构化数据和站点地图会随文章目录更新。生产域名使用 `APP_URL`，本地和测试环境仍禁止索引；配置为生产环境后才输出正式 canonical 和站点地图链接。接入这些基础标记不等于保证收录或排名。

工具目录、功能介绍和常见问题保留在首页。导航从首页直接滚动，从其他页面先回到首页再定位，地址不带哈希或定位参数。博客、文章详情和价格保留独立页面。首页“看看效果”只滚动到预览区域。页脚保留公开资源和法律链接，不出现登录或账户入口。
