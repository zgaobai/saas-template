## 配置与接入的区别

已预设本地、staging 和 production 配置及对应构建、部署、迁移命令，资源与密钥按环境独立。两个云端环境仍使用占位域名和数据库 ID，待账号资源创建后填写；不会自动创建资源或复制本地凭据。见 [环境配置](environments.md)。

站点名称、套餐、模型、服务地址和环境密钥可以配置；还需要在服务商侧创建商品、设置 webhook、验证发件域、登记 OAuth 回调，以及绑定 D1/R2。配置后要做一次沙箱验收，不能仅凭填入 key 判断可上线。

密钥仅在本地 `.dev.vars` 或 Cloudflare Secrets。前端只获得功能是否启用等公开状态。`npm run config:check` 只报告缺项，不显示密钥值。
